# Paddlio Page Structure

Diese Struktur ist die Zielposition der vorhandenen Funktionen.

## Phone

Bottom Navigation mit maximal fünf Einträgen:

1. Heute
2. Kalender
3. Training
4. Team
5. Mehr

Analyse, Polar, Akademie, Material, Ziele, Import/Export und Einstellungen bleiben über `Mehr` oder Kontextkarten erreichbar.

## Tablet

Kompakte Sidebar:

- Heute
- Kalender
- Training
- Plan
- Team
- Analyse
- Polar
- Akademie
- Mehr

Standardarbeitsfläche für Trainer:

- Kalender in der Mitte
- Vorlagen rechts
- Detail/Training als Split View

## Desktop

Kompakte Sidebar:

- Übersicht
- Kalender
- Plan
- Training
- Team
- Analyse
- Polar
- Akademie
- Aufgaben
- Nachrichten
- Wettkampf
- Material
- Datenimport
- Einstellungen

Adminfunktionen werden nur für berechtigte Rollen sichtbar.

## Fachbereiche

| Bereich | Unterstruktur |
|---|---|
| Heute | Tageskarte, Wochenplan, Belastung, Polar, Rückmeldungen, Aufgaben, Nachrichten, Schnellzugriff |
| Kalender | Tag, Woche, Monat, Jahr, Liste, Vorlagen, Quick Edit |
| Training | Übersicht, Heute, Plan, Einheiten, Journal, Vorlagen, Historie |
| Plan | Woche, Monat, Saison, Jahr, Wiederholungen, Wochen kopieren, Wochenvorlagen |
| Team | Übersicht, Sportler, Trainer, Gruppen, Anwesenheit, Aufgaben, Nachrichten, Vereinsnews |
| Analyse | Training, Belastung, Herzfrequenz, Soll/Ist, Wettkampf, Ziele, Rekorde |
| Polar | Verbindung, Sync, letzte Einheit, HF/Zonen, GPS, Zuordnung, Historie |
| Akademie | Lernen, Kurse, Lektionen, Quiz, Fortschritt, Redaktion |
| Wettkampf | Kalender, Meldungen, Läufe, Ergebnisse, Strafsekunden, Bestzeiten |
| Material | Boote, Paddel, Zubehör, Status, Wartung, Trainingseinsatz |
| Import/Export | Import, Export, Profile, Historie, Berichte |
| Einstellungen | Profil, App, Datenschutz, Syncstatus, Hilfe |
| Admin | Nutzer, Rollen, Vereine, Gruppen, Freigaben, Systemstatus, Audit |
