# Phase 3.3 Desktop Professional Workspace

## Ziel

Desktop ist die professionelle Planungs- und Verwaltungsstation.

## Layout

- Kalender dominiert die Mitte.
- Kontext rechts: Vorlagen, Training-Detail, Aufgaben oder Konflikte.
- Controls sind kompakter als auf Phone.

## Umsetzung in dieser Phase

- Kalender- und Vorlagenbereich werden dichter geführt.
- Rechte Kontextbereiche sind auf Desktop sticky.
- Training-Aktionen im Kalender sind kompakter.

## Funktionsstatus

Vorhandene Funktionen bleiben erhalten:

- Woche kopieren
- Mehrfachauswahl
- Vorlagen
- Jahresansicht
- Saisonansicht
- Detaildrawer
- Soll/Ist
- Aufgaben- und Feedback-Register
