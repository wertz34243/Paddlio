# Tablet Calendar Architecture

## Prinzip

Kalender ist die Arbeitsfläche. Er zeigt Trainings, Wettkämpfe, Termine und Trainingslager, aber keine dauerhaften Statistik- oder Erklärungskarten.

## Toolbar

- Zeitraum: Zurück, Heute, Weiter.
- Ansicht: Tag, 3 Tage, Woche, Monat, Liste, Saison.
- Werkzeuge: Vorlagen, Filter, Aktionen, Mehrfach.

## Kontext

Landscape:

- Mitte: Kalender.
- Rechts: ein Kontextbereich.

Portrait:

- Kalender volle Breite.
- Kontext als Slide-over.

## Entfernt aus Tablet-Kalenderfläche

- Dauerhafte Statistik-KPI-Reihe.
- Dauerhaft offene Filter.
- Wochenplan-Zusatzliste unter dem Kalender.
- Doppelte Trainingsdetail-Ebene.
