# Tablet Template Toolbox

## Rolle

Vorlagen sind auf Tablet Werkzeugkasten, nicht eigener Seiteninhalt.

## Struktur

- Training
- Woche
- Saison
- Favoriten
- Meine
- Verein
- System

## Darstellung

Vorlagen werden kompakt als Zeilen dargestellt:

- Farbindikator
- Titel
- Kategorie
- Dauer
- Intensität

Lange Beschreibungen bleiben im kompakten Zustand ausgeblendet.

## Bedienung

- Vorlage antippen öffnet Quick Edit.
- Drag auf Kalender öffnet Quick Edit mit Datum aus Drop-Ziel.
