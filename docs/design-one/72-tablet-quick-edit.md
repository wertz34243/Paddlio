# Tablet Quick Edit

## Problem

Quick Edit lag bisher als großes Formular über dem Kalender. Auf Tablet ist das ungünstig, weil Trainer während der Planung den Wochenkontext sehen müssen.

## Neue Lösung

Auf Tablet/Desktop erscheint Quick Edit im rechten Kontextpanel.

Wichtige Felder:

- Datum
- Start
- Dauer
- Boot
- Zuweisung
- Ziel
- Trainer
- Ort
- Wiederholung

Weitere Details bleiben über den vorhandenen vollständigen Planungsweg erreichbar.

## Ergebnis

Der Kalender bleibt sichtbar, während Werte geprüft und eingefügt werden.
