# Paddlio One Phase 2.5 - Template Library Integration

## Vorlagenbereiche

Die Vorlagenbibliothek ist direkt im Kalender integriert.

- Favoriten
- Zuletzt verwendet
- Meine Vorlagen
- Vereinsvorlagen
- Systemvorlagen
- Wochenvorlagen
- Saisonbausteine

## Vorlagekarte

Jede Vorlage zeigt kompakt:

- Symbol
- Titel
- Bereich
- Dauer
- Intensität
- Favoritenstatus

## Einfügen

Desktop und Tablet unterstützen Drag & Drop auf einen Kalendertag. Zusätzlich können Vorlagen per Klick geöffnet und über Quick-Edit geplant werden.

Phone nutzt eine einfachere Auswahl ohne überladene Drag-and-Drop-Erwartung.
