# Phone Navigation Gestures

## Unterstützte Gesten

- Edge Swipe von links nach rechts schließt die aktuelle mobile Ebene.
- Swipe Down schließt mobile Sheets.

## Betroffene Bereiche

- Kalenderfilter
- Trainingsdetail
- Quick Edit
- Feedback
- Live Training

## Schutz vor Datenverlust

Bei Eingabezuständen wird nicht still geschlossen:

- Quick Edit fragt vor dem Verwerfen.
- Feedback fragt vor dem Verwerfen.
- Live fragt vor dem Schließen.

## Grenzen

Der mehrstufige Training-Wizard verwendet weiterhin sichtbare Zurück/Weiter/Abbrechen-Buttons. Eine vollständige gestenbasierte Wizard-History wurde bewusst nicht eingeführt, weil das eine größere Flow-Änderung wäre.
