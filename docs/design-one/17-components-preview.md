# Paddlio One Components Preview

Stand: Phase 1, Branch `develop`

## Route

`/components-preview`

Die Route ist nur in Development aktiv. Production rendert diese Preview nicht.

## Parameter

| Parameter | Werte |
|---|---|
| `theme` | `dark`, `light`, `highContrast` |

Beispiel:

`/components-preview?theme=light`

## Enthaltene Beispiele

- Buttons
- Status-Chips
- KPI-Karten
- Listenzeilen
- Formularfelder
- Empty State
- Error State

## Zweck

Die Preview dient als interne Abnahmefläche für Phase 1 und als Referenz für spätere Seitenmigrationen.
