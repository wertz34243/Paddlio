# Mobile Layout Fixes

## Behobene Problemklassen

- Kalender-Header wurde auf `Kalender` reduziert.
- Vorlagen-Schalter im Phone-Kalender wurde entfernt.
- Woche-kopieren und Mehrfachauswahl werden auf Phone nicht angezeigt.
- Kalenderfilter und Kalenderstatistiken werden auf Phone ausgeblendet.
- Drop-Hinweis `Vorlage hier ablegen` wird auf Phone durch `Keine Einträge` ersetzt.
- Phone-Kalender erhält zusätzlichen Bottom-Abstand gegen Bottom Navigation.
- Kalenderkarten und Trainingsblöcke erhalten `min-width: 0` und Textumbruch.
- Lange Titel werden begrenzt und brechen nicht aus Karten heraus.

## Noch zu prüfen

- reale iPhone-Safe-Area im Browser
- 200-%-Zoom
- lange Vereins- und Gruppennamen
