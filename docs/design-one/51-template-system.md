# Template System

## Trennung

Vorlagen sind kein Kalenderinhalt. Sie liefern Bausteine für Kalender und Training.

## Arten

- Einzeltraining
- Wochenvorlage
- Monatsvorlage
- Saisonbaustein

## Geräteverhalten

| Gerät | Verhalten |
|---|---|
| Phone | kompakte Liste, verwenden, ansehen, favorisieren |
| Tablet | Vorlagen neben Kalender, Touch Drag & Drop |
| Desktop | Vorlagenbibliothek, Drag & Drop, Verwaltung |

## Alternative zu Drag & Drop

Jede Vorlage muss auch über `Vorlage verwenden` bzw. `In Kalender einfügen` nutzbar sein.
