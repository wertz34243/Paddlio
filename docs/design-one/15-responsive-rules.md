# Paddlio One Responsive Rules

Stand: Phase 1, Branch `develop`

## Phone

- einspaltig
- Bottom Navigation
- große Hauptaktionen
- wenige Karten gleichzeitig
- Fokus auf Heute, Training, Feedback, Kalender und Team

## Tablet

- Sidebar möglich
- Kalender plus Detail oder Vorlagen
- mittlere Dichte
- Touch bleibt wichtig
- Landscape bevorzugt Split View

## Desktop

- kompakte Sidebar
- mehrere Bereiche gleichzeitig
- flachere Karten
- kompaktere Buttons und Inputs
- Dashboard-, Kalender-, Analyse- und Verwaltungsflächen dichter

## Ultrawide

- zusätzliche Kontextspalte möglich
- keine unbegrenzt breiten Textzeilen
- Inhaltsbreiten bleiben begrenzt

## Deep Links

Gerätefähigkeit und Rollenlogik bleiben getrennt. Phase 1 stellt nur UI-Grundlagen bereit.
