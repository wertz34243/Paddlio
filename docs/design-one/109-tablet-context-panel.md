# Tablet Context Panel

## Zustände

Der Kontextbereich zeigt immer genau einen Zustand:

- Vorlagen
- Filter
- Quick Edit
- Trainingsdetail

## Verhalten

- Training antippen: Kontext wird Detail.
- Vorlage verwenden: Kontext wird Quick Edit.
- Filter öffnen: Kontext wird Filter.
- Vorlagen öffnen: Kontext wird Toolbox.

## Vorteil

Der Kalender bleibt sichtbar und wird nicht durch modale Desktop-Formulare verdeckt.
