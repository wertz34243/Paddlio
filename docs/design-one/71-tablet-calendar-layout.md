# Tablet Calendar Layout

## Landscape

Ab ca. 1024 px Breite:

- Kalender: flexible Hauptfläche
- Kontext: ca. 32 Prozent, mindestens 300 px
- Navigation bleibt außerhalb dieses Arbeitsbereichs

Der Kalender erhält damit den größten Teil der Fläche. Trainingsblöcke sind kompakter, Titel werden begrenzt und Aktionen kleiner dargestellt.

## Portrait

Unter ca. 1024 px:

- einspaltiger Kalender
- Kontext darunter beziehungsweise als ruhiger Bereich

So entstehen keine drei gequetschten Spalten.

## Drop-Zonen

Leere Tage zeigen im normalen Zustand nur den leeren Zustand. Der aktive Ablagehinweis erscheint erst, wenn tatsächlich eine Vorlage gezogen wird.
