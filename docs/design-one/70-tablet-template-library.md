# Tablet Template Library

## Struktur

Die Vorlagenbibliothek ist auf Tablet verdichtet und trennt die Vorlagenarten:

- Training
- Woche
- Saison

Trainingsvorlagen besitzen zusätzlich kompakte Filter:

- Favoriten
- Meine
- Verein
- System

## Kompakte Zeile

Eine Trainingsvorlage zeigt nur:

- Kategorie-Icon
- Titel
- Kategorie
- Dauer
- Intensität

Beschreibungen erscheinen nicht dauerhaft im kompakten Panel. Dadurch bleiben Vorlagen lesbar, auch wenn die rechte Spalte schmaler ist.

## Drag & Drop

Trainingsvorlagen bleiben ziehbar. Alternativ kann eine Vorlage angetippt werden, um Quick Edit zu öffnen.
