# Tablet Responsive Final

## Breakpoints

Paddlio nutzt weiterhin die bestehenden Geräteklassen:

- Phone: unter 768 px
- Tablet: 768 bis 1199 px
- Desktop: ab 1200 px

Diese Phase ändert die Phone-Shell nicht.

## Tablet Landscape

- Kalender und Kontextpanel teilen die Breite.
- Kalender bleibt Hauptfläche.
- Builder nutzt Formular plus Live-Vorschau.
- Touchziele bleiben mindestens 44 px hoch.

## Tablet Portrait

- Kalender bleibt volle Arbeitsfläche.
- Kontextbereiche laufen als Drawer/Overlay.
- Builder fällt auf einspaltige Struktur mit statischer Vorschau zurück.

## Desktop

Desktop wird nicht neu gestaltet. Gemeinsame Komponenten können später weiterverwendet werden, aber Desktop-Dichte und professionelle Multi-Panel-Workflows bleiben eine separate Phase.
