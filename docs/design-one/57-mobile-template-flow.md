# Mobile Template Flow

## Ziel

Vorlagen sollen auf Phone schnell auswählbar sein, ohne eine große Kartenwand zu erzeugen.

## Phone-Darstellung

- kompakte Zeilen/Karten
- Titel maximal kurz sichtbar
- Kategorie, Dauer und Intensität als Nebeninfo
- Favorit oder Verwenden als kleine Aktion

## Workflow

Phone nutzt Auswahl statt Drag & Drop:

1. Vorlage öffnen
2. verwenden
3. Datum/Uhrzeit wählen
4. speichern

## Tablet und Desktop

Drag & Drop bleibt Tablet/Desktop vorbehalten. Dort sind Vorlagen weiterhin Planungswerkzeuge neben dem Kalender.
