# Mobile Training Flow

## Ziel

Ein Training soll auf Phone schnell erstellt oder bearbeitet werden können, ohne direkt alle Detailfelder zu zeigen.

## Neuer Assistent

Der mobile Ablauf besteht aus vier Schritten:

1. Art
2. Wann?
3. Was?
4. Notiz / weitere Einstellungen

## Vorteile

- weniger sichtbare Felder pro Schritt
- klare primäre Aktion
- kompaktere Darstellung auf kleinen Geräten
- bestehende Speichern-Logik bleibt erhalten

## Tablet und Desktop

Ab Tabletgröße werden die Schritte nicht künstlich versteckt. Dort kann das Formular dichter und vollständiger erscheinen.
