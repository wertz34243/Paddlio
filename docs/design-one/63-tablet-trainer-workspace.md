# Phase 3.2 Tablet Trainer Workspace

## Ziel

Tablet ist das Trainergerät für Planung und Arbeit am Wasser.

## Landscape

Struktur:

- links kompakte Navigation
- Mitte Kalender
- rechts Vorlagen oder Training-Detail

## Portrait

Struktur:

- Kalender als Hauptfläche
- Vorlagen/Details über Drawer oder Slide-over

## Umsetzung in dieser Phase

- Tablet-Kalender behält die zweispaltige Arbeitsfläche.
- Vorlagenbereich bleibt neben dem Kalender verfügbar.
- Kontextbereich bleibt sticky und damit beim Arbeiten erreichbar.

## Bewusst nicht erweitert

Kein neues Polar, keine neue Analyse, keine KI, keine neuen Verwaltungsfunktionen.
